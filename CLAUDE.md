# LOOPFORM: правила проекта

Анимированный лендинг-презентация демо-бизнеса LOOPFORM. Контент лежит в `CONTENT.md`, техническое задание в `PROMPT_v2.md`, ход работы в `PROGRESS.md`, архитектура в `README.md`.

## Правила кода

- Без точки с запятой в конце строк.
- Строки только в двойных кавычках.
- Никаких комментариев в файлах кода (`.ts`, `.tsx`, `.scss`, `.glsl`).
- Никаких эмодзи в коде и интерфейсе.
- Профессиональные английские имена, один компонент на файл, стили рядом: `Name.tsx` + `Name.module.scss`.
- Все цвета, размеры шрифтов, отступы, длительности и easing берутся только из `src/styles/tokens.scss` и `src/animation/tokens.ts`.
- TypeScript strict, без `any`.
- Подробные объяснения только в `README.md` на русском: архитектура, назначение каждой папки, как работает каждая анимация, шейдер печати, система частиц, связка Lenis + ScrollTrigger + three.js. README обновляется в конце каждого этапа.

Правило про точки с запятой действует для TS, TSX и GLSL-фрагментов там, где язык это позволяет. В SCSS и GLSL они обязательны по синтаксису языка, поэтому там остаются.

## Контент

- Тексты переносятся из `CONTENT.md` в `src/content/ru.ts` дословно. Тексты, которые задаёт `PROMPT_v2.md`, тоже лежат в `ru.ts`.
- Нельзя добавлять отзывы клиентов, цифры, цитаты и логотипы партнёров, которых нет в этих двух файлах.
- Если данных нет, поле остаётся пустым, а вопрос попадает в `PROGRESS.md`.

## Референсы

Референсы: dialedcoffee.com (главный), itsoffbrand.com, vizcom.com. Не скачивать и не копировать их код, 3D-модели, изображения, шрифты, тексты и логотипы. Воспроизводятся только приёмы, ритм и хореография. Всё, что не описано в ТЗ и `CONTENT.md`, решается по образцу этих сайтов.

## Порядок работы

Работа идёт по разделу 12 `PROMPT_v2.md` автономно, без остановок после этапов. После крупного этапа запускается `scripts/shoot.mjs`, скриншоты сверяются с хореографией. Отличия от ТЗ записываются в `PROGRESS.md`.

## Технические договорённости

- `tokens.scss` не выводит CSS при подключении. Переменные `:root` выводит только `globals.scss` через миксин `root-tokens`.
- Цвета для three.js читаются из CSS-переменных через `src/three/palette.ts`, а не дублируются в TS.
- Шрифты лежат в `public/fonts` как собственные сабсеты. В JetBrains Mono нет символа `₸`, поэтому цены набираются шрифтами Unbounded или Inter.
- Телефон и компьютер используют одну хореографию. Различия допускаются только в SCSS и в количестве частиц. Отдельная ветка есть только для reduced motion.
- В коде нет GSAP pin. Закрепление делает CSS `position: sticky`, а ScrollTrigger только считает прогресс.
- Высокочастотные значения прогресса лежат в мутируемых объектах стора и читаются в `useFrame`. Реактивные поля стора меняются только при смене состояния.
